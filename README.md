## Hallazgo principal
La cumbia es el único género que el mercado peruano sostiene por sí solo (42 % de sus canciones con tracción exclusivamente peruana, el doble que el urbano). Recomendación: fichar cumbia con tracción local, invertir en el debut y promocionar en playlists algorítmicas y redes.
